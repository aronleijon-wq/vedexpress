# Värme Hem

Skapa en hemsida som säljer ved och ha en kalkyl där du kan räkna ut hur mycket ved du behöver beroende på hur många kaminer eller hur storlek i huset som värmer upp tillräckligt för säsongen. Sedan kan du trycka på köp nu. Det ska vara seriöst och professionellt. Det ska vara väldigt simpelt för alla att förstå. Inget mer än så. Men vi kör hemkörning och du får exakt det som ska krävas för att värma upp ditt hus. Simpel hemsida, tack!
